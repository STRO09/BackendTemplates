# Backend Templates

A collection of production-ready backend starter templates designed to eliminate repetitive project setup and provide clean, scalable foundations for modern backend development.

This repository is intended to grow into a library of reusable templates across multiple languages and frameworks, each following consistent architectural principles and production-ready practices.

---

# 🎯 Vision

Instead of rebuilding the same project structure, authentication flow, exception handling, configuration, and boilerplate for every new project, this repository aims to provide ready-to-use starter templates that can be cloned and extended immediately.

Each template focuses on:

- Clean Architecture
- Feature-Based Organization
- Production-Ready Structure
- Scalability
- Maintainability
- Best Practices

---

# 📦 Available Templates

| Framework | Description | Status |
|-----------|-------------|--------|
| Spring Boot (No Authentication) | Clean Spring Boot starter with standardized responses, exception handling and feature-based architecture | ✅ Available |
| Spring Boot + JWT | JWT Authentication + Refresh Tokens | 🚧 Planned |
| Spring Boot + JWT + OAuth2 | JWT, Refresh Tokens, Google/GitHub OAuth | 🚧 Planned |
| Spring Boot + JWT + OAuth2 + Passkeys | Complete authentication starter with WebAuthn support | 🚧 Planned |
| Node.js | Express/NestJS backend starter | 📅 Planned |
| Go | Production-ready Go backend starter | 📅 Planned |
